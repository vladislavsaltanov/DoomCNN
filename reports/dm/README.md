# Deathmatch: отчёты по срезам

Агент по пикселям играет deathmatch в ViZDoom (`cig.wad`) против 7 встроенных ботов. Спек v2.0 (MAP02, учитель-читер,
четыре головы действий). Полный журнал: `research_log_dm.md`. Картинки и видео каждого среза лежат в
`artifacts/dm/<та же папка>`.

## Главный результат

Ученик по пикселям после PPO **обошёл учителя-читера**: 13.20 фрага на 60 свежих матчах при 11.65 у учителя (113 %,
разность +1.55 [−0.25, +3.30]). На базовой графике 15.60 против 12.78, на незнакомой — 89 % учителя.

| шаг | доля фрагов учителя (свежие seed) |
|---|---|
| имитация (E4, `dm3_m1_aux`) | 39 % |
| DAgger (E5, `dagger_sp_r2`) | 41 % |
| PPO (E6, `ppo_kl_03000k`) | 88 % |
| PPO + движение по карте (E6b, `ppo_explore_01001k`) | 101 % |
| **PPO + случайные точки появления и редкие районы (E6c, `ppo_e6c_01001k`)** | **113 %** |

## Как пользоваться

- В каждой папке лежат отчёт среза (`.md`), его графики (`.png`) и числа (`.json`).
- Парные сравнения моделей на одних и тех же матчах: `scripts/dm/dm_compare_reports.py`.
- Посмотреть модель в игре: `python -m doomagent.dm.dashboard` (панель) или
  `.venv\Scripts\python scripts/dm/dm_play.py --who <модель> --record <файл>.mp4` (видео 35 кадров/с).
